# ADIL SAMI — Personal Portfolio

A modern, responsive personal portfolio website for showcasing skills, projects, and contact information.

## Built With

- HTML5
- CSS3
- Google Fonts
- Responsive design
- Smooth scrolling

## Project Structure

```text
personal-portfolio
├── index.html
├── css
│   └── styles.css
├── assets
│   └── profile-photo.jpg
└── README.md
```

## Features

- Modern hero section with profile photo
- About section
- Technical skills section
- Landing Page project showcase
- GitHub and LinkedIn links
- Email contact link
- Responsive mobile-friendly layout
- Circular professional profile image
- Available for work status indicator
- Smooth navigation between sections

## Run Locally

1. Open the project folder in Visual Studio Code.
2. Open `index.html` with Live Server.

Or run:

```powershell
python -m http.server 8000
```

Visit:

```text
http://localhost:8000
```

## Customization

- Edit personal information in `index.html`.
- Replace `assets/profile-photo.jpg` with your own image.
- Update colors and layout in `css/styles.css`.
- Add future projects inside the Projects section.
