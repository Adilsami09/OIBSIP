# H2D2 Static Landing Page

A bold, responsive streetwear and activewear landing page for H2D2.

H2D2 stands for **Hardwork. Honest. Dedication. Discipline.** The page uses a black, white, and neon-lime visual system with editorial typography and urban lifestyle imagery.

## Built With

- HTML5 semantic markup
- CSS3 responsive layout and styling
- Google Fonts: Archivo Black and Space Grotesk
- External Unsplash imagery

## Project Structure

```text
static-landing-page
├── index.html
├── css
│   └── styles.css
├── js
│   └── script.js
└── README.md
```

## Included Sections

- Hero section with H2D2 tagline and shop CTA
- Navigation links for Home, Shop, Collections, About, and Contact
- Featured product showcase for hoodies, joggers, and tees
- New arrivals grid
- H2D2 brand-code statement
- Lifestyle imagery and brand story section
- High-contrast Shop Now CTA banner
- Footer with social links, newsletter form, and brand statement

The page is intentionally static. The product controls, newsletter form, and shopping links are presentation elements ready to be connected to a commerce backend later.

## Run Locally

1. Open the project folder in your code editor.
2. Open `index.html` directly in a browser.

No build tools or package installation are required.

## Customization

- Edit content and links in `index.html`.
- Update colors, typography, spacing, and responsive rules in `css/styles.css`.
- Replace the external image URLs in `css/styles.css` with local assets when moving to production.
- `js/script.js` is intentionally unused because this is a static landing page.
